# Manuguru Town Guide

A responsive community website designed to help residents, students, visitors, and newcomers discover useful places and services in Manuguru, Telangana, India.

## About the Project

The Manuguru Town Guide aims to bring useful local information together in one place. Instead of searching across multiple websites and apps, users can explore local businesses, public services, transport information, educational institutions, healthcare facilities, and places of interest.

The project is being developed as a community-focused platform, with the goal of making local information easier to find and helping people discover businesses and services in their town.

## Features

- **Local Business Directory** — Shops, restaurants, hotels, grocery stores, and other businesses.
- **Education** — Schools, colleges, and training institutions.
- **Healthcare** — Hospitals, clinics, and pharmacies.
- **Government & Public Services** — Municipal services, banks, ATMs, and other useful public facilities.
- **Transport** — Bus stations, railway information, and other local transport resources.
- **Places to Visit** — Temples, theatres, landmarks, and community locations.
- **Search & Filtering** — Find listings by name or category.
- **Contact Options** — Call links for listings with available phone numbers.
- **Map Directions** — Open Google Maps to search for a listed place.
- **Responsive Design** — Designed for mobile phones, tablets, and desktop computers.

Some features and sections are still being developed. Information availability depends on the data collected and verified for each listing.

## How to Run Locally

1. Download or clone this repository.
2. Keep the website files together in the same folder.
3. Open `index.html` in a web browser.

No backend server is required for the current static website.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Select the `main` branch and the `/(root)` folder.
5. Click **Save** and wait for deployment.

## Data Accuracy & Community Contributions

Local information may be incomplete, outdated, or awaiting verification. Phone numbers, addresses, operating hours, government contacts, and transport schedules should be confirmed before being relied upon.

The project aims to improve the accuracy and usefulness of its information through community contributions.

If you know a local business, public facility, landmark, or service that should be included, consider submitting a correction or suggestion through the repository's Issues section.
