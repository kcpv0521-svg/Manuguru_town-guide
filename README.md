# Town Guide — Manuguru

A responsive static website starter built from the MANUGURU directory spreadsheet.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — category selection, search, filtering, sorting, phone links and map directions
- `data.js` — 110 listing records imported from the spreadsheet

## Publish with GitHub Pages
1. Create/open your GitHub repository (for example, `town-guide`).
2. Upload all four website files to the repository root.
3. Commit the changes to the `main` branch.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then Save.
7. Wait for GitHub Pages to publish the site.

## Important data note
The directory was compiled from public directory leads and earlier collected data. Names, phone numbers, addresses and current operating status may be incomplete or outdated. Verify each record before treating it as confirmed. This site does not claim that unverified listings are current.
