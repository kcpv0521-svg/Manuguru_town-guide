# Manuguru Town Guide

Premium responsive bilingual English/Telugu town directory for Manuguru, Telangana.

## Files
- `index.html` — website layout
- `style.css` — responsive visual design
- `script.js` — search, filters, sorting, bilingual toggle, call and map directions
- `data.js` — 123 directory records, including IDs 111–123

## Publish on GitHub Pages
1. Open https://github.com/kcpv0521-svg/Manuguru_town-guide
2. Replace the four files in the repository root with these files.
3. Commit the changes to `main`.
4. In Settings → Pages, select deploy from `main` and folder `/(root)`.
5. Refresh https://kcpv0521-svg.github.io/Manuguru_town-guide/ with Ctrl+F5.

## Accuracy
Some phone numbers and locations are community-supplied and may be incomplete or outdated. Verify important details directly. This is a community directory, not an official government website.
